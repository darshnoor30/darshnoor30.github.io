02 SOC lab · Network monitoring

SentinelNet

A Python-based SOC monitoring project that captures live TCP/UDP traffic, detects suspicious services, records categorized alerts, and presents security activity through a Streamlit analytics dashboard.

  • Live capture with Scapy-based IP, TCP, and UDP packet processing.
  • Detection rules for exposed or suspicious services including Telnet, SMB, RDP, and known backdoor ports.
  • 17 automated tests covering rule matches, scan detection, cooldowns, packet normalization, analytics, and CLI behavior.
  • Analyst views for severity distribution, top threat ports, trends, and activity timelines.

04 Network security · Firewall assurance

FirewallGuard

An explainable firewall-rules auditor that parses JSON and iptables-save configurations, normalizes policy semantics, and produces evidence-backed findings for security review.

Deterministic analysisIdentifies public administrative and database exposure, permissive policies, duplicate rules, and conservative shadowing without presenting the posture score as CVSS.
Traceable assuranceMaps relevant findings to selected NIST CSF 2.0, CIS Controls 8.1, and MITRE ATT&CK references with clear non-certification boundaries.
Verified deliveryIncludes a CLI, Streamlit dashboard, PDF/JSON/CSV exports, Docker support, CI, 44 automated tests, and 91% measured coverage.
